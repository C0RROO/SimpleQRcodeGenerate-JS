# QR Generate — генератор и сканер QR-кодов

Веб-приложение для создания и распознавания QR-кодов. Работает полностью в браузере — без сервера, без регистрации. Подходит для телефона и десктопа.

## Демо

[c0rroo.github.io/SimpleQRcodeGenerate-JS](https://c0rroo.github.io/SimpleQRcodeGenerate-JS/)

## Возможности генератора

### Шесть типов содержимого

- **Ссылка** — открывает сайт при сканировании
- **Текст** — до ~2900 символов
- **Wi-Fi** — сохранение сети с логином и паролем
- **Гео** — координаты с открытием в Яндекс.Картах
- **E-mail** — готовое письмо с темой и телом
- **Телефон** — сразу набирает номер

### Дизайн

- **9 форм модулей**: квадраты, мягкие, точки, ромбы, кресты, звёзды, гексы, полосы, столбцы
- **5 форм уголков**: квадрат, скруглённые, круг, лист, точки
- **Палитра** из 20 цветов + HEX-ввод + нативный пикер
- **Градиент** с настройкой угла
- **Прозрачный фон** — экспорт без подложки
- **Рамка с подписью** (например, «SCAN ME»)
- **Логотип в центре** — QR строится с пустой зоной, лого не перекрывает модули

### Экспорт

- **PNG** до 2048×2048
- **SVG** — векторный, для печати и типографики
- **Копирование** в буфер обмена
- **Автосохранение** в историю (последние 30 кодов)

## Возможности сканера

- **Камера** (на телефоне \ ноутбуке) — с переключением фронтальная/задняя, подсветкой
- **Загрузка файла** — drag&drop, выбор, вставка из буфера
- **Распознавание** с нескольких попыток: разные размеры, бинаризация по порогам, инверсия
- **Умный разбор результата** — отдельные карточки для ссылок (с фавиконом), Wi-Fi (SSID/шифрование/пароль), гео (встроенная карта Яндекс), e-mail, телефона, текста
- **Кнопка «Сделать QR»** — перенос отсканированного содержимого обратно в генератор

## Интерфейс

- **Плавающее окно предпросмотра** — перетаскивается, прилипает к краям, на телефоне превращается в шторку над панелью навигации
- **Пошаговая настройка**: Содержимое → Дизайн → Детали (с возвратом на любой шаг)
- **Живой предпросмотр** — изменения применяются мгновенно
- **Две темы**: графит и светлая

## Стек

Чистый HTML + CSS + JavaScript. Библиотеки: `qrcode-generator` (генерация), `jsQR` (распознавание). Никаких фреймворков и сборщиков.

## Использование

1. Склонируйте репозиторий
   ```bash
   git clone https://github.com/C0RROO/SimpleQRcodeGenerate-JS.git
   ```
2. Откройте `index.html` в браузере
3. Заполните поля — QR появится сразу в окне предпросмотра
4. Скачайте PNG или SVG
